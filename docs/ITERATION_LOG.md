## 迭代 1：可复用的时间轴

**评估**：继续保留时间轴、问答和现有 PDF；把多种输出放在同一个导出入口。
先解决渲染和解析边界问题，使后续字幕与笔记操作有可靠基础。

**计划**：提取共享时间轴模型；安全渲染搜索高亮与问答 Markdown；增加 Markdown、JSON、
SRT、VTT 导出，注明从现有转录推断的字幕结束时间；增加实际边界条件的回归验证。

**完成（21:15，已推送 `06af14f`）**：新增统一导出对话框、Markdown / JSON / SRT / WebVTT 本地导出、
筛选结果导出、可选原文；保留 PDF。共享时间轴解析与导出类型，删除重复的 Window API 声明。
搜索高亮进行文本转义；问答 Markdown 经 DOMPurify 清理，时间戳只在文本节点中转换；
外部链接仅允许 HTTP(S)。

**验证**：16 个 Vitest 用例通过；`npm run build` 通过；ESLint 无错误、9 条警告（基线 41 条）。
真实 Chromium 浏览器配合模拟 Electron API 检查完整/筛选导出、SRT、取消、错误反馈、
Escape 保留筛选、900×600 最小窗口布局。未调用收费模型或真实视频下载；原生文件对话框
与视频服务的端到端检查留待后续轮次。

**取舍**：用单一导出窗口收拢格式、原文和筛选范围，避免继续堆积时间轴工具栏按钮。
字幕缺失的结束时间清楚标注为推断值；JSON 不包含模型调用凭证和接口信息。

**完成（21:35，已推送 `8fb54ca`）**：导入 UTF-8 SRT / WebVTT / VidStudio Markdown / JSON；字幕以两分钟分组，
提供独立原文阅读区与前后片段导航，明确标记未生成 AI 摘要。缓存使用内容哈希去重；
导入资料进入历史，重新打开保留原始毫秒时间、重叠提示和片段标识。无效输入保留当前资料。

**相关修正**：问答上下文使用本地关键词匹配选取相关章节与原文，限制上下文长度并提示证据不足；
长句截取保留匹配内容。切换资料前清理旧会话与搜索状态；忙碌时避免切换造成状态混用。
历史图标改为本地组件，修复远程图标与应用 CSP 冲突。

**验证**：30 个 Vitest 用例通过；完整构建、类型检查通过；ESLint 无错误。
Chromium 配合模拟 IPC 验证导入、阅读导航、坏文件保护、历史恢复和 JSON 再导出，
确认示例字幕的 `1.125 → 3.750` 秒时间没有被取整。未调用收费模型。

**取舍**：字幕导入只做确定性的整理，不自动发起 AI 摘要；需要问答时再使用配置的模型。

## 迭代 4：资料检索与可靠历史

**重新评估**：历史现在能够长期保留，但标题搜索不足以找回学过的具体概念。
沿用现有历史入口，搜索章节、原文和个人笔记，直接跳到命中片段；同时修复并发 JSON 写入的丢记录风险。

**计划**：资料全文检索、收藏筛选、搜索结果片段预览和定位；历史序列化写入、原子替换与损坏保护。

**完成**：将原历史下拉菜单合并为资料库窗口；本地检索标题、章节要点、原文、标签、
个人笔记（包括旧版本片段），显示命中时间与上下文。点击结果定位章节并展开原文，
阅读器滚动至对应原句。支持收藏筛选、重命名、50 条分页、⌘/Ctrl+K 和 Escape。

**可靠性**：历史变更排队、原子替换、有效版本备份；损坏历史不再伪装为空列表或被覆盖。
缓存与搜索索引在同一事务中更新；旧缓存懒加载建索引，无效缓存隔离。
移除记录保留缓存与笔记；没有缓存时打开视频来源，由用户明确点击解析，不自动消耗模型。

**验证**：51 个测试通过；完整构建与类型检查通过；ESLint 无错误、7 条既有警告。
Chromium 配合模拟 IPC 检查自动聚焦、收藏筛选、重命名、搜索定位、移除取消/确认、
缓存保留、快捷键和 900×600 布局。发现并修复搜索框吞掉 Escape 的行为。

**取舍**：搜索采用本地文字片段匹配，覆盖中文短词，不引入额外模型服务或向量库。
显示各资料的前三个命中，更多内容可在打开后的时间轴中继续查找。

## 迭代 5：可靠的资料问答

**重新评估**：资料和个人记录已能保存与找回，但问答仍是易丢失的临时状态。
流式回答期间清空消息可能访问已删除的数组元素，也缺少停止生成能力。

**计划**：对话取消与请求隔离、按资料保存会话、失败重试、复制和导出；优先确保切换资料与迟到事件不会污染其他会话。

**完成**：每份资料独立保存对话，恢复历史和中断的部分回答；停止生成中止模型及联网搜索。
所有事件携带请求标识，清空和切换后忽略迟到事件。支持最后一条失败/停止回答的重试、
复制与 Markdown 导出，保存失败草稿在会话内保留并可重试。

**可靠性**：流式回答每秒保存检查点；请求最长 3 分钟；按来源串行保存，过时快照不覆盖新内容。
SSE 处理跨字节中文、CRLF、无换行结尾、多个工具调用；意外断流明确标记未完成。
原始对话完整保存在本机，发送模型的历史另行限制最近消息与字符预算；不保存系统上下文或密钥。

**验证**：70 个回归用例通过；完整构建及类型检查通过。
Chromium 配合模拟 IPC 验证停止、迟到事件、重试、刷新恢复、复制、导出参数及生成中清空；
中文输入法组合态的 Enter 不发送。未使用真实模型或 Tavily 配额。

**取舍**：每份资料保留一条连续对话，暂不增加多会话管理；避免把简单的资料问答变成独立聊天产品。

拒绝迟到的新后台任务。停止期间保持来源切换和新解析禁用。
播放预览使用唯一临时文件，成功后原子发布；取消、空输出或失败清理临时文件。

**验证**：94 项单元测试通过，包含真实父子进程、忽略 SIGTERM 的子进程、同时退出多个任务、
缺失程序及取消转码缓存保护；完整构建和类型检查通过。真实 macOS Electron 离线/重启流程及
4 项浏览器交互回归均通过，停止期间禁用操作与迟到解析结果已覆盖。ESLint 无错误。

## 迭代 16：真实媒体验收发现的 macOS 退出边界

**重新评估**：在真实打包应用中，用本地生成的一秒 AVI 验证 FFmpeg 转码、缓存复用和立即取消。
转码与缓存正常，但第一次立即取消遇到 `kill EPERM`，离线资料测试未覆盖这个系统边界。

**定位与修复**：在线核对 [Apple XNU 的进程组信号实现](https://github.com/apple-oss-distributions/xnu/blob/xnu-12377.1.9/bsd/kern/kern_sig.c#L1709)，
确认 macOS 会在进程已退出、尚未回收时返回 EPERM。仅在 macOS 对该错误间隔 30 毫秒重试两次，
允许事件循环回收退出进程；真正持续的权限错误仍返回失败，不把失败当作停止成功。

**验证**：110 项本地单元测试、类型检查、构建通过，ESLint 无错误。
新增 macOS 专属用例覆盖短暂错误恢复及持续错误保留。重新打包后，真实 FFmpeg 输出 H.264、
缓存复用和 20 次立即取消全部通过；其中实际捕获 3 次短暂 EPERM，重试后均确认进程组已消失。
所有媒体为本地生成的合成数据，无网络、账号或模型调用。

## 本轮产品取舍与后续候选

- 保留一个时间轴、一个资料库、一个导出入口；字幕、视频解析结果和个人笔记共用数据与导航。
- 新用户可先使用离线示例及字幕导入；需要视频理解或问答时再配置模型，默认不读取剪贴板和浏览器账号。
- 先保证记录可恢复、结果可带走、后台任务可停止；暂不增加云同步、多任务队列或第二套笔记界面。
- 下一轮优先补充真实视频服务的受控集成验收，以及 Windows / Linux 发行包验证；正式发布还需签名配置。
- 可继续评估资料间关联检索、复习提醒与集合导入，但需先确认实际使用反馈，避免功能重复。

**已知边界**：本轮未调用收费模型、下载真实视频或读取真实浏览器账号；这些在线路径不能由离线回归代替。
依赖审计无 high / critical；仍有 8 项 moderate 构建依赖告警，待上游兼容修复；ESLint 留有 5 条
已净化 HTML 输出对应的规则警告。Windows / Linux 已通过桌面自动化，安装包仍待人工验收。
